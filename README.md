# MCP Server Pennylane - Owl Agency

Serveur MCP pour connecter Dust à Pennylane.

## Déploiement Vercel

1. Importer ce repo sur Vercel
2. Variables d'environnement :
   - `PENNYLANE_API_TOKEN`
   - `PENNYLANE_API_BASE_URL` = `https://app.pennylane.com/api/v2`
3. Déployer

## URL MCP

```
https://[projet].vercel.app/api/mcp
```

## Tools

- `pennylane_health_check` - Statut comptabilité
